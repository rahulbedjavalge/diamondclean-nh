# Diamond Clean NH Website Prompt

Build a premium, modern, responsive website for a professional cleaning company called **Diamond Clean NH** based in Berlin.

This is NOT a basic cleaning company website.

The design should feel luxurious, trustworthy, elegant and modern.

Think Apple × Tesla × Premium German service company.

Use large white spaces, smooth animations, glassmorphism where appropriate, rounded cards, subtle shadows, premium typography and clean layouts.

The website must be fully responsive for desktop, tablet and mobile.
